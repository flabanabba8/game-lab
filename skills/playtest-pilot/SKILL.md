---
name: playtest-pilot
description: Playtest a selected X11 game window and record measured evidence.
---

Use `computer_use` to list the game window and PID, then `playtest_start` immediately. Do not call native `computer_use` capture: start returns the game image and supports X visuals that native capture cannot. If it is not ready, follow its reason; inspect the game state and do not judge a loading or title screen as gameplay.

For each requested expectation use `playtest_check` sequentially, waiting for its result before calling another with intent, expected and one action: `{"action":"hold","keys":["Right"],"seconds":1.5}`, `{"action":"key","keys":"Escape"}`, or `{"action":"click","coordinate":[x,y]}`. The user approves each check once. Inspect all before, during and after images and the measured facts; if a preview is too small, magnify a region from its saved step and frame with `playtest_read_value`; a camera following a player can make scenery move in the opposite direction. Measurements and panel detection are hints, not verdicts. For a pause use a short tap with `pause_probe:true` and `resume_key` set to the same pause key. Check the frozen and resumed images; a frozen frame alone does not prove a pause.

When a panel blocks input, inspect its visible keys, check with the appropriate dismiss key, and retry the expectation. Use `playtest_read_value` with `[left, top, right, bottom]` screen fractions to magnify a HUD or pause-menu counter. To read a past pause frame after resuming, pass its `step` and `frame: "after"` or `frame: "one second later"`. Treat OCR as an untrusted hint and associate a number with its visible label. A visible value that contradicts the expectation is a failure; quote the real value. Try every requested expectation even if an earlier one is uncertain; restart when needed to inspect the initial state. Record each verdict using `playtest_observe` and finish with `playtest_report`. Use uncertain when the images do not prove the result. Do not infer hidden state or replay an unobserved action.
